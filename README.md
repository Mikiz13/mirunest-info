MiruNest 🌸

Your anime, your journey.

MiruNest is a personal, non-commercial Android application designed to make anime tracking simple, modern, and intuitive.

The app integrates with the official MyAnimeList API to help users manage their anime library, track watched episodes, update watch status, and explore anime information.

Features

- Anime library and watch progress tracking
- MyAnimeList account synchronization
- Episode and watch status management
- Anime search and detailed information
- Modern interface optimized for Android phones and tablets

Development Status

🚧 MiruNest is currently under active development. MyAnimeList integration and core tracking features are planned and not yet available.

Technology

Built with Kotlin, Jetpack Compose, and Material Design 3.
